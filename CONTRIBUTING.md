# Katkıda Bulunma

Hata bildirimi ve özellik talepleri GitHub Issues üzerinden yapılabilir.

Bir hata bildirirken mümkünse şunları ekleyin:

- Simple File Manager sürümü
- Android sürümü
- Cihaz modeli
- Sorunu yeniden üretme adımları
- Beklenen davranış
- Gerçekleşen davranış
- Varsa ekran görüntüsü / hata mesajı

Kod değişikliği göndermek isterseniz, değişikliğin amacını açıklayan bir pull request açabilirsiniz.

## Lisans notu

Bu depo herkese açıktır ancak şu anda bir açık kaynak lisansı tanımlanmamıştır. Ayrı bir lisans eklenene kadar kaynak kodun kullanım ve yeniden dağıtım koşullarının otomatik olarak açık kaynak olduğu varsayılmamalıdır.
